# 试用反馈表（草稿）

对应 [产品路径](PRODUCT_PATHWAY.md) B 阶段。分两次填：**第一份**在试用者第一次成功输入当天（或放弃当天）填，**第二份**一周后填。题目刻意少，大部分是选择题，每份 3–5 分钟。

给维护者的使用说明（不发给试用者）：

- 装之前不做讲解，只给安装包链接和这份表。试用者卡住来问，照常帮，但在文末“维护者记录”里记一笔。
- 可以原样贴进腾讯问卷 / Google Forms；题号保持不变，方便跨人汇总。
- 汇总时写清人数和分母（“5 人里 3 人……”），不换算成百分比。
