**标题：** 做了个免费开源的语音输入 TypeAloud，我现在给 Claude Code 写提示词基本不打字了

**正文：**

这大半年我跟 AI 说的话比跟人说的还多。给 Claude Code、Codex 写提示词，动不动一两百字，中英文夹着，打字又慢又累，就想用说的。

【这一段写你自己真实试过什么、为什么不满意。我能确认的事实只有：Wispr Flow、Typeless 是订阅制、云端识别。别的产品哪里不好，只写你亲身碰到的。】

所以自己做了一个，现在是我每天的主力输入方式，一天大概说三十来次。

**它做的事很简单：** 按住 Ctrl+Shift 说话，松手，字出现在光标所在的地方。双击是免按住模式，说完再按一下。

几个我自己在意、所以花了功夫的地方：

- **识别在本机做。** 默认用千问的 Qwen3-ASR（跑在 llama.cpp 上），录音不离开电脑。不用注册，不用 API key，没有字数限制。M 系列的 Mac 上，说十几秒的话松手后一秒左右出字。
- **中英混说。** "把这个 PR rebase 到 main 上再跑一遍 CI"这种句子能正常出来。
- **长段不丢。** 说得久了会在录音过程中分段识别；哪一段失败了，录音和失败原因都留在历史记录里，可以重新转写，不会一句话白说。
- **嗯、呃这些口头禅会自动去掉**，引号里的不动。
- 想用云端也行，填自己的 OpenAI 或 Groq key，从你电脑直连，不经过我。

老实说的部分：

- Mac 是我天天在用的，最稳。Windows 有安装包，但我手头没有 Windows 机器做完整测试，算测试版，欢迎踩坑。
- 本地模型要先下载一次；内存 8G 以下的机器跑本地会慢。
- 目前只做"说话变文字"，改口修正、自动分段这类润色还在做。
- 会发匿名的使用次数统计（不含任何文字和录音），设置里可以看到发了什么，也可以关。

## 预备回答

- **"和 Handy 有什么区别？"** Handy 很好，模型也多，也有千问。区别在中文这头：TypeAloud 装好默认就是千问，不用在几十个模型里挑；说得久了会边录边分段识别；嗯、呃这类中文口头禅会去掉（Handy 的口头禅清理目前只有英、德、法）。英文为主的话 Handy 更成熟。【如果你当初没选 Handy 另有原因，照实写。】两个都免费，可以都装上比一比。
- **"为什么不用 Whisper？"** 中文和中英混说上千问明显好，尤其是连着说不停顿的时候 Whisper 容易不加标点。
- **"以后会收费吗？"** 本地转写不会。以后的云端润色只传文字，成本很低，我来出。
- **"Linux？"** 有安装包，但录音卡在 WebKitGTK 上，目前用不了，不想骗人说能用。
