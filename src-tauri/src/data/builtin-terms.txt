# Built-in spellings for names the local engines write with the wrong case,
# spacing or a letter or two off. One term per line, written the way it should
# appear. `terms.rs` decides when a heard form is close enough; a term that is
# also an ordinary word (Cursor, Linear, Swift) is only ever protected, never
# forced. A user's dictionary entry wins over a line here.
